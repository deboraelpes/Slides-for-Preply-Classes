# Ser, Estar e Ter — Aula do Emílio

Slide interativo de português (verbos SER, ESTAR e TER) com jogos embutidos.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub e suba estes arquivos (`index.html` precisa ficar na raiz).
2. Vá em **Settings → Pages**.
3. Em "Source", selecione a branch (geralmente `main`) e a pasta `/ (root)`.
4. Salve. Em alguns minutos o GitHub vai gerar um link tipo `https://seu-usuario.github.io/nome-do-repositorio/`.
5. Envie esse link para o Emílio.
